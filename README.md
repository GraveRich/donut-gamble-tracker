# Donut Gamble Tracker

Client-side Fabric mod for **Minecraft 1.21.11**, made for **DonutSMP**, by __Death____.

This repository only hosts the release files (the mod jar and its signed update file). The mod needs a licence key from __Death____.

## Install

1. Install **Fabric Loader** (0.16 or newer). Fabric API is not needed.
2. Download `donut-gamble-tracker-<version>.jar` from the [latest release](../../releases/latest).
3. Put it in your `.minecraft/mods` folder and remove any older `donut-gamble-tracker` jar.
4. Start the game, press **J** and paste your licence key on the License page.

## Updates

The mod checks this repository when Minecraft starts. A new version downloads in the background, is checked against __Death____'s signature and is installed when you close the game.

**Coming from 2.0.9 or older:** install 2.0.10 by hand once (steps above). Older versions look for updates at the previous address and cannot find it any more.
